# Changelog

## 2.2.1

- Record both sides of a Dock or direct-click transition, including when the source app was reached
  through a swipe.

## 2.2.0

- Track app activations from clicks and Command-Tab so the previous app is always the one used most
  recently.
- Keep utility-triggered activations out of recent-app ordering to preserve multi-app navigation.
- Simplify application preferences to exclusions; recent order is now automatic.

## 2.1.0

- Redesign Settings with a native sidebar, clearer alignment, and compact sections.
- Replace the glossy icon with a reproducible, flat three-finger gesture mark.
- Add universal release builds, Developer ID signing, notarization, and GitHub release automation.

## 2.0.0

- Add persistent Settings, app exclusions and ordering, a switch HUD, Launch at Login, wake recovery,
  and rapid-swipe handling.
